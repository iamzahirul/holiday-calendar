# বাংলাদেশ ছুটির ক্যালেন্ডার 🇧🇩

> সরকারি ছুটির পূর্ণ তালিকা + **পরবর্তী ছুটির কাউন্টডাউন** ("ঈদের আর কত দিন?") + এক ক্লিকে **ক্যালেন্ডারে (.ics) এক্সপোর্ট** — সম্পূর্ণ অফলাইন।

## ✨ Features

- ✅ **২০২৬-এর সরকারি ছুটির পূর্ণ তালিকা** (গেজেট-ভিত্তিক, ২৭ দিন) + **২০২৭** (চন্দ্র-নির্ভর তারিখ আনুমানিক চিহ্নসহ)
- ✅ **পরবর্তী ছুটির হিরো-কাউন্টডাউন** — কত দিন বাকি, এক নজরে
- ✅ প্রতিটি ছুটিতে **"কত দিন বাকি" চিপ** — গতগুলো "সম্পন্ন"
- ✅ **সার্চ** (ঈদ, পূজা…) + **ক্যাটাগরি ফিল্টার** (জাতীয় · ধর্মীয় · আন্তর্জাতিক · বিশেষ)
- ✅ **📅 .ics এক্সপোর্ট** — ডাউনলোড করে সরাসরি গুগল ক্যালেন্ডার/আউটলুক/অ্যাপল ক্যালেন্ডারে ইমপোর্ট করুন
- ✅ সাধারণ/নির্বাহী ছুটি আলাদা চিহ্নিত · শুক্র-শনি হাইলাইট · মাস-ভিত্তিক গ্রুপ
- ✅ কাউন্টডাউন টেক্সট কপি করে বন্ধুদের পাঠানোর বাটন
- ✅ ১০০% অফলাইন — একটি মাত্র `index.html`, কোনো ডাটা কালেকশন নেই

## 🧪 টেস্ট স্কোর

| টেস্ট | রেজাল্ট |
|---|---|
| ডাটা যাচাই + গেজেট তারিখ মিলানো + হেল্পার + রেন্ডার + ICS | **৫০/৫০** |

তথ্যসূত্র: বাংলাদেশ সরকারের ২০২৬ সালের ছুটির গেজেট অনুসরণকারী একাধিক সোর্স ক্রস-চেক করা (শবে কদর ১৭ মার্চ, ঈদুল ফিতর ২১ মার্চ, ঈদুল আজহা ২৭ মে, ১৫ আগস্ট বাদ — নতুন "জুলাই গণঅভ্যুত্থান দিবস" ৫ আগস্ট সহ)।
